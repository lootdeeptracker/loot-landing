Data import

Three imports

Import tournaments from SharkScope

  1. Select "Basic Search" or "Advanced Search" to filter by period.
  2. Select your player group (Player Group).
  3. Click the player name in the table and open the "Tournaments" tab.
  4. Click "Download all as CSV", just above the list.
Upload the file in Import CSV in Loot.

Import data into the GG Fixer

  1. Open the GG Poker app.
  2. Go to PokerCraft and open "My Tournaments".
  3. Select the period and click "SHOW".
  4. Download "Game Summaries" (green button).
Upload the .zip files in GG Fixer in Loot. Loot bulk-fixes the errors SharkScope brings in GG Poker tournaments.

You can send several files at once.

Import game stats

  1. In your tracker (HM3, PT4 or H2N), select the hands for the period.
  2. Export the hand history (hand histories).
  3. In Loot, open Stats and click Import.
  4. Select or drop the files. Loot calculates your stats; if the volume is large, it goes into a queue and runs in the background.
Works with any network. The calculation is done by Loot itself.
